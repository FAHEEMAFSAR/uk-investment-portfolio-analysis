# UK Investment Portfolio Analysis

**Power BI & PostgreSQL project analyzing simulated UK investment portfolios.**  
Includes client investments, asset allocation, returns, and monthly performance with interactive dashboards.

---

## 🚀 Project Overview

This project demonstrates a full investment portfolio analysis workflow, from database creation to interactive reporting in Power BI.  
It is designed to showcase skills relevant for:

- Investment Reporting Analyst  
- Financial Data Analyst  
- Business Intelligence (BI) Analyst
